= Catalog Information Conformance

You can check for API catalog information conformance using a custom or MuleSoft-provided ruleset. API catalog information is associated with an API asset in Exchange in the asset portal. 

A MuleSoft-provided ruleset that validates API catalog information is:

* API Catalog Information Best Practices

See xref:find-and-fix-conformance-issues.adoc[] for an overview of ways to validate conformance and determine why conformance failed.

[[fix-api-catalog-issues-in-exchange]]
== Fix API Catalog Conformance Issues in Exchange

Fix issues by updating the API catalog information associated with the API so that it conforms to the rules it violated. For information about updating API catalog information using Exchange, see xref:exchange::to-describe-an-asset.adoc[].
