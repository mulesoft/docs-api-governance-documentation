= Finding and Fixing Conformance Issues
:page-aliases: view-conformance-status-in-exchange.adoc

To find and fix API conformance:

. Initiate validation of APIs against rulesets in:
+
* <<validate-in-profiles,API Governance>> for all supported API aspects
* <<validate-in-design-center,Design Center>> for  specifications
* <<validate-in-cli,Anypoint CLI>> for specifications
+
. View conformance issue details as follows: 
+
* For an API validated using active profiles in API Governance, view conformance information in the:
+
** <<view-spec-issues-in-report, Validation report in API Governance>> for all supported API aspects
** <<view-conformance-in-exchange,Conformance Status page in Exchange>> for specifications
+ 
* To view conformance information for an API regardless of whether it's governed by an active profile, you can use:
+
** xref:find-conformance-issues.adoc[Design Center] for specifications
** xref:find-conformance-issues.adoc[Reports generated through CLI] for specifications
+
. Fix the issues using xref:find-conformance-issues.adoc[Design Center].

[[view-conformance-in-gov-report]]
== View Conformance Information in the Validation Report

To view conformance information in the governance validation report:

. In the API Governance console, select the *Governed APIs* tab.
. If the API has a *Not Conformant* badge, click *View Report* for information about the conformance issue.
.. View all issues:
+
Click *View Details* for a ruleset the API is nonconformant to. 
.. View issues for a selected aspect only:
... Select an aspect of the API in the Conformance Breakdown section of the report.
... Click *View Details* for a ruleset the API is nonconformant to.
