= Finding and Fixing Conformance Issues
:page-aliases: view-conformance-status-in-exchange.adoc

To find and fix API conformance:

. Initiate validation of APIs against rulesets in:
+
* xref:create-profiles.adoc[API Governance] for all supported API aspects
* xref:find-conformance-issues.adoc[Anypoint Code Builder, Design Center, Anypoint CLI] for specifications only
+
. View conformance information as follows: 
+
* For a governed API validated using an active profile, view conformance information in the:
+
** <<governance-validation-report,Validation report in API Governance>> for all supported API aspects
** <<view-conformance-in-exchange,Conformance Status page for APIs in Exchange>> or
<<view-governed-apis-for-rulesets,Governed APIs page for rulesets in Exchange>> for specifications only
+ 
* For an API specification, regardless of whether it's governed, you can use:
+
** xref:find-conformance-issues.adoc[Anypoint Code Builder, Design Center, or
reports generated through CLI]
+
. Fix the issues using:
+
** xref:find-conformance-issues.adoc#fix-in-acb[Anypoint Code Builder] or xref:find-conformance-issues.adoc#project-errors[Design Center] for specifications
** xref:fix-documentation-conformance-issues.adoc[Exchange] for documentation
** xref:fix-catalog-info-conformance-issues.adoc[Exchange] for catalog information
** xref:fix-instance-conformance-issues.adoc[API Manager] for instances

== View Conformance Information in the Validation Report

View a comprehensive governance validation report in API Governance or API Manager.

To view conformance information in the governance validation report:

. In the API Governance console, select the *Governed APIs* tab.
. If the API has a *Not Conformant* badge, click *View Report* for information about the conformance issue.
.. View all issues:
+
Click *View Details* for a ruleset the API is nonconformant to. 
.. View issues for a selected aspect only:
... Select an aspect of the API in the Conformance Breakdown section of the report.
... Click *View Details* for a ruleset the API is nonconformant to.
