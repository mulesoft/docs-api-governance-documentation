= Viewing Conformance Status 

For APIs governed by active profiles, you can view conformance information in the:

* <<governance-validation-report,Governance validation report>>
* <<view-conformance-in-exchange,Conformance Status page in Exchange>>

Nonconformance messages give information about conformance issues and contextual links direct you to the best place to fix them.
